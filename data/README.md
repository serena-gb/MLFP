# Data

Tracked files:

- `avGFP_WT.fasta`: wild-type avGFP amino-acid sequence.
- `avGFP_single_mutants.csv`: curated single-mutant activity table.
- `descriptors/ZSCALE.csv`: Z-scale amino-acid descriptors.
- `descriptors/VHSE_descriptor.csv`: VHSE amino-acid descriptors.

Large/generated data assets are not tracked. See `../data_manifest.yaml`.
